## About

Finance Mentor AI is a beginner-friendly web application that helps users learn personal finance step-by-step. It combines an AI-powered tutor, structured lessons, interactive quizzes, and practical tools like a financial calculator — all wrapped in a clean, modern dashboard experience.

### Key Features

- **AI Tutor Chat** — Ask finance questions and get smart, contextual answers
- **Structured Lessons** — Progress through modules covering budgeting, investing, savings, and more
- **Interactive Quizzes** — Test your knowledge and track quiz accuracy over time
- **Financial Calculator** — Run practical calculations for loans, investments, and budgets
- **User Profiles** — Track learning progress, achievements, streaks, and customize preferences
- **Progress Dashboard** — Visualize completed lessons, XP earned, and topics mastered
- **Achievements System** — Earn badges like Beginner Investor, Quiz Master, and Consistency Badge

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, shadcn/ui
- **Backend:** Lovable Cloud (authentication, database, real-time sync), Lovable AI(Google Gemini)
- **Charts:** Recharts
- **Routing:** React Router
